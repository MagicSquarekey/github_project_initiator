> Ένας τοπικός εκκινητής για όλα τα έργα σας στο GitHub: κατάσταση, εκκίνηση/διακοπή και ενημέρωση με ένα κλικ.

Υπηρεσία Node.js χωρίς εξαρτήσεις με πίνακα ελέγχου μίας σελίδας. Παρακολουθεί τα έργα σας, τα εκκινεί και τα σταματά και κατεβάζει ενημερώσεις — χωρίς ποτέ να αλλάζει τον κώδικά τους.

## Γρήγορη εκκίνηση

```bash
node src/index.js
```

Άνοιγμα: http://127.0.0.1:8780

Απαιτεί Node.js 20+. Τα Windows υποστηρίζονται πλήρως· Linux/macOS χρησιμοποιούν το ενσωματωμένο επίπεδο πλατφόρμας.

## Δυνατότητες

- **Κατάσταση με μια ματιά** — κατάσταση λειτουργίας, θύρες, PID και χρόνος λειτουργίας, ανανέωση κάθε 3 δευτ.
- **Εκκίνηση / διακοπή / επανεκκίνηση** — χρησιμοποιεί το δικό του σενάριο εκκίνησης κάθε έργου.
- **Ενημέρωση με ένα κλικ** — αποθηκεύει προσωρινά τις μη καταχωρημένες αλλαγές, ενημερώνει και τις επαναφέρει· σε αποτυχία κάνει rollback.
- **Οποιαδήποτε στοίβα** — Next.js, FastAPI, δυαδικά Go, Godot, pygame και υπηρεσίες pip σε έναν πίνακα.
- **Προσθήκη έργων από τον πίνακα** — επιλέξτε φάκελο· η εντολή εκκίνησης και η θύρα εντοπίζονται αυτόματα, χωρίς επεξεργασία JSON.
- **Δίγλωσσο UI και φωτεινό/σκοτεινό θέμα** — εναλλαγή από την κεφαλίδα, απομνημόνευση τοπικά.
- **Μόνο εκκινητής** — δεν εκτελεί ποτέ git init ούτε γράφει στα διαχειριζόμενα έργα.

## Ασφάλεια και απομόνωση

- Ακούει μόνο στο 127.0.0.1, χωρίς έλεγχο ταυτότητας (τοπικό εργαλείο ενός χρήστη).
- Η τοπική διαμόρφωση και τα αρχεία καταγραφής εξαιρούνται από το git· δημοσιεύεται μόνο ένα φορητό παράδειγμα.
- Δεν γράφει ποτέ στα διαχειριζόμενα έργα· η μόνη εγγραφή είναι η ενημέρωση που ξεκινάτε εσείς.
